# 🔬 AmadeusGPT-UF-Installer
A single `.bat` file you can double click to get started on **AmadeusGPT-UF**.

---

## 🪰 Usage
* 🖱️ **Click** on the `uf-amadeus-installer.bat` file in this repository.
* 📥 **Click** the download icon to install it onto __your computer__.
* 📂 Move the file to where you want your AmadeusGPT folder to be.
* ⚙️ **Double click** the `.bat` file to run it.
* ✅ Once it finishes running, AmadeusGPT should be installed. *You can close the terminal window.*
* 🖥️ There will be a shortcut **on your desktop** labeled **'UF Amadeus GPT'**.

Then, as simple as that, you're done! You can double click this shortcut to launch 🚀

---

## Notices
* This installer adds git and uv to your machine if not present. These are required for it to work.
* This installer uses a PAT key to clone a private repo. This is a read-only key.
* Be careful when running .bat files on your PC; only use it if installed from a trustworthy source.
