# 🔬 AmadeusGPT-UF-Installer
A single `.bat` file you can double click to get started on **AmadeusGPT-UF**.

---

## 🪰 Usage
* 🖱️ **Click** on the `uf-amadeus-installer.bat` file in this repository.
* 📥 **Click** the download icon to install it onto __your computer__.
* 📂 Move the file to where you want your AmadeusGPT folder to be.
* ⚙️ **Double click** the `.bat` file to run it.
* ✅ Once it finishes running, AmadeusGPT should be installed. *You can close the window.*
* 🖥️ There will be a shortcut **on your desktop** labeled **'UF Amadeus GPT'**. You can click this to launch! 🚀
